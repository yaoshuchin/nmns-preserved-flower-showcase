## 📖 校內研習緣起與核心主題

本系統為**南投縣立南投國民中學 115 學年度數學領域教師校內在職增能研習**之數位成果網，由南投國中數學領域教學輔導團隊主辦策劃。

大自然是精密的數學家與最頂級的藝術家。本展示打破傳統學科藩籬，透過現代生物化學**「植物細胞有機置換永生技術（Preserved Flowers）」**，將自然界中演化沉澱的幾何秩序——**斐波那契數列（Fibonacci sequence）**、**黃金分割比例（$\Phi = 1.618$）**、**對稱與碎形（Fractals）**，轉化為一盆盆充滿手作溫度且歷久彌新的空間立體花藝。

## 📚 15 頁永生花完整教學大綱

本教學大綱為南投國中跨領域教師研習專用之 15 堂核心知識架構，兼具植物學科學厚度與美感實作引導：

| 頁碼 | 核心知識單元 | 科學與數學面向 | 實作與教學重點 |
| :---: | :--- | :--- | :--- |
| **P.1** | **永生花主題導入：讓花停留在最美的時刻** | 時間凝結 ‧ 幾何美學 | 南投國中跨領域手作課程主題導覽，跨領域核心精神定位 |
| **P.2** | **什麼是永生花／不凋花** | 1991 專利置換科學 | 源自 1991 法國專利的植物細胞置換工藝，保留真花水嫩觸感與彈性 |
| **P.3** | **永生花、乾燥花、索拉花、香皂花的差異** | 材質大百科 ‧ 觸感辨析 | 四大人氣花材物理特性、製程原理、耐用度與香氛吸附能力全方位評比 |
| **P.4** | **永生花的保存原理：脫水、脫色、保鮮液與乾燥** | A液脫色 × B液甘油重構 | 乙醇有機溶劑脫水脫色，甘油（$C_3H_8O_3$）滲透吸濕性保濕與低溫陰乾定型 |
| **P.5** | **常見花材：玫瑰、康乃馨、繡球花、葉材** | 花冠構造 ‧ 植物學結構 | 玫瑰（主視覺焦點）、康乃馨（密實浪褶）、繡球花（打底基石）、兔尾草與松果 |
| **P.6** | **花材選擇與品質判斷** | 特級品鑑 ‧ 開度彈性指標 | 6~7 分滿開適期檢驗、花瓣回彈彈性觸感、色彩均勻度與無斑駁檢驗標準 |
| **P.7** | **工具、材料與工作安全** | 標準作業資材 ‧ 安全第一 | 乾燥花泥（灰黑高密度）、花剪、鑷子、低溫熱熔膠操作規範與防燙指套 |
| **P.8** | **色彩搭配與主色、輔色、點綴色** | 60-30-10 黃金法則 | 60% 主色（奠定基調）+ 30% 輔色（柔和過渡）+ 10% 點綴色（活力亮點） |
| **P.9** | **花藝構圖：比例、層次、焦點與留白** | $\Phi = 1.618$ ‧ 三角錐幾何體 | 花器與花冠黃金分割比例、三點定面不等邊三角錐、焦點微揚 15° 與留白呼吸感 |
| **P.10** | **基礎技法：鐵絲、綠膠帶、黏著與固定** | 力學支點 ‧ 結構補強 | 花瓣微溫開花術、#26 鐵絲穿刺法（Piercing）、45°斜角膠帶活化纏繞與 60°斜插 |
| **P.11** | **實作一：玻璃罩永生花** | 360° 全視角 ‧ 微型景觀 | 微型自然景觀重現，梯形花泥固定、繡球打底、主花定錨與防塵封罩 |
| **P.12** | **實作二：永生花相框** | 半浮雕美學 ‧ L 型動線 | 深度 3~5cm 立體框，半浮雕（Bas-relief）空間堆疊、異材質底板與照片互動 |
| **P.13** | **實作三：小型永生花束** | 螺旋花腳（Spiral） | 同向旋轉花莖手法、黃金分割結紮點、韓式波浪霧面包裝紙與精緻禮盒提袋 |
| **P.14** | **保存、清潔與常見問題** | 45%~60% RH ‧ 防潮急救 SOP | 亞熱帶氣候對策、受潮出油除濕機急救 SOP、嚴禁澆水、吹風機弱冷風除塵 |
| **P.15** | **成果展示、學習評量與延伸創作** | STEAM 多元評量 ‧ 生活實踐 | 南投國中校園現場展示與線上數位典藏、幾何比例與工藝純熟度量表、擴香花禮與生活美學延伸 |
