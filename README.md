## 📖 策展緣起與核心主題

本系統為**國立自然科學博物館（NMNS）植物園公開展示主題特展**之數位成果展示系統，攜手**南投縣立南投國民中學數學領域輔導團隊**共同策劃。

大自然是精密的數學家與最頂級的藝術家。本展示打破傳統學科藩籬，透過現代生物化學**「植物細胞有機置換永生技術（Preserved Flowers）」**，將自然界中演化沉澱的幾何秩序——**斐波那契數列（Fibonacci sequence）**、**黃金分割比例（$\Phi = 1.618$）**、**對稱與碎形（Fractals）**，轉化為一盆盆充滿手作溫度且歷久彌新的空間立體花藝。

## 📚 15 頁永生花完整教學大綱

本教學大綱為科博館特展與南投國中跨領域教師研習專用之 15 堂核心知識架構，兼具植物學科學厚度與美感實作引導：

| 頁碼 | 核心知識單元 | 科學與數學面向 | 實作與教學重點 |
| :---: | :--- | :--- | :--- |
| **P.1** | **展覽封面與策展主題** | 黃金螺旋 ‧ 空間美學 | 臺中科博館植物園特展公開展示導覽、跨域核心精神定位 |
| **P.2** | **永生花的前世今生** | 1991 專利置換科學 | 傳統植物標本、乾燥花與現代永生花（Preserved Flowers）演進與本質差異 |
| **P.3** | **植物細胞與水分生理學** | 細胞膨壓 ‧ 液泡置換 | 顯微鏡下花瓣細胞壁三維結構、水分蒸散與色素氧化褐變生理機制 |
| **P.4** | **化學置換兩階段核心原理** | A液脫色 × B液甘油重構 | 乙醇有機溶劑脫水、甘油（$C_3H_8O_3$）滲透吸濕性保濕與環保染料固色 |
| **P.5** | **花材種類與植物學特徵** | 花冠構造 ‧ 多樣性評估 | 繡球花（傘房花序）、玫瑰（重瓣厚實）、兔尾草（羽狀伸展）、松果（木質化） |
| **P.6** | **自然界的幾何美學：費氏數列** | $F_n = F_{n-1} + F_{n-2}$ | 松果雙向螺旋（8/13）、向日葵種子排列、花瓣數量的數學演化最優解 |
| **P.7** | **黃金分割與對數螺旋** | $\Phi = \frac{1+\sqrt{5}}{2} \approx 1.618$ | $3:5$ 與 $5:8$ 花籃高度比例平衡、137.5° 黃金角、手把圓弧的自然延伸 |
| **P.8** | **對稱、碎形與空間層次** | Fractal Dimension ‧ 碎形自相似 | 鏡像對稱、破對稱動態平衡、繡球花傘房花序自相似性與立體景深 |
| **P.9** | **實作工藝前置：資材與安全** | 模組化資材 ‧ 實驗安全 | 乾燥花泥（灰黑高密度）、花剪、鑷子、低溫熱熔膠操作與防燙規範 |
| **P.10** | **核心技法：開花術與接枝技巧** | 力學支點 ‧ 結構補強 | 花瓣微溫綻放術（5分轉8分開）、#26 鐵絲穿刺法（Piercing）與膠帶斜纏繞 |
| **P.11** | **立體構圖：黃金三角與空間律動** | 三角錐幾何體 ‧ 空間呼吸 | 三點定面原理、主花副花高低錯落、保留適度負空間（Negative Space） |
| **P.12** | **色彩學與異材質對比** | 互補色相 ‧ 質地共振 | 冰藍 vs 焦糖金冷暖對比、透光歐根紗緞帶 vs 粗獷編織藤籃質感交融 |
| **P.13** | **科學典藏與長期養護指引** | 45%~60% RH ‧ 抗紫外線 | 亞熱帶氣候對策、受潮出油除濕機急救 SOP、嚴禁澆水、弱冷風除塵 |
| **P.14** | **跨領域教育：從校園到科博館** | STEAM 跨域 ‧ 108 課綱素養 | 教師增能賦能、動手學幾何、科博館社會教育平台與館校合作典範 |
| **P.15** | **策展總結：凝結自然之美** | Beauty in Eternity ‧ 生命共鳴 | 定格自然時光、傳遞手作溫度、世界無處不在的幾何之美與生命奇蹟 |

3. **🎯 3. B. 科普問答 (Science FAQ Mode)**：
   - 6 大核心問題手風琴平滑折疊，內建綠底螢光關鍵詞，附「查看簡報對應頁 ➔」秒速切換。
